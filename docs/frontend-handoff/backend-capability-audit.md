# Backend Capability Audit (evidence-based)

**Method:** every claim traces to `src/` file:line. Status scale: `IMPLEMENTED` (code +/or tests), `PARTIAL` (works but incomplete), `PLANNED` (documented intent, no code), `MISSING`, `UNVERIFIED`.

Global wire rules: `ValidationPipe {whitelist, forbidNonWhitelisted, transform}` (`src/main.ts:39-45`); `AllExceptionsFilter` REST `{statusCode,message,timestamp}` / GraphQL `GraphQLError {extensions.code}` (`src/common/filters/all-exceptions.filter.ts:23-83`); `cookie-parser` on (`src/main.ts:37`); CORS allow-list `FRONTEND_URL + CORS_ORIGINS`, credentials true (`src/common/cors.ts`, `src/main.ts:69-73`); Swagger UI `/api`, bearer `JWT-auth` (`src/main.ts:49-65`); RMQ microservice `noAck:false, prefetch 10` (`src/main.ts:24-35`).
